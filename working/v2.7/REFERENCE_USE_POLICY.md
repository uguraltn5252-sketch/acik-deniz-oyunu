# FOULWAKE v2.7 — REFERENCE USE POLICY

Status: DRAFT / ACTIVE
Canonical baseline: v2.6 STABLE / LOCKED
Active branch: v2.7-design

## Purpose
User-provided reference images are art-direction references only unless the user explicitly asks to reuse or edit the actual asset.

## Default mode
`REFERENCE_USE_MODE = STYLE_ONLY`

References may inform:
- line character and line-weight range
- hatch / cross-hatch density
- limited-color balance
- old-print texture strength
- adult-caricature deformation level
- dry-humor level
- illustration / information hierarchy
- title-banner scale and visual character
- atmosphere and quality target

References may NOT supply final artwork content by default.

## Absolute prohibitions unless explicitly requested by the user
- crop / paste from a reference image
- tracing
- pixel-level reuse
- cut-out character reuse
- cut-out object reuse
- cut-out background reuse
- direct reuse of a reference card illustration
- direct placement of an uploaded reference asset in a final card artwork area
- same-face reuse
- unnecessary replication of the same pose, camera angle, silhouette, object layout or visual joke
- collage construction from reference fragments

## New-card rule
Every new card illustration must be derived in this order:
1. canonical card mechanic
2. player-facing meaning
3. current world/story context
4. ACTIVE_DRAFT design system
5. FOULWAKE visual language
6. user reference images — style only

`NEW CARD = NEW ILLUSTRATION`

## Similarity QA
Every representative or final illustration must be checked for:
- reference crop/paste
- tracing feel
- pixel-level reuse
- same-face or same-character transfer
- same pose or composition without mechanical reason
- reused background or major object
- collage feel
- whether the scene is genuinely specific to the card mechanic

Any direct reuse, crop/paste, tracing or obvious repackaging is `FAIL` and must be replaced before the visual gate can pass.

Core principle:
**PRESERVE THE LANGUAGE. REINVENT THE SCENE.**
