# FOULWAKE v2.7 — DESIGN WORKFLOW

Status: DRAFT / NOT LOCKED

## Source-of-truth model

1. **GitHub** holds canonical mechanics, card text, IDs, counts, story, the master visual standard, validation notes and approved exports.
2. **Canva** is the primary editable production workspace for card templates, card fronts/backs, print sheets and rulebook layout.
3. **Adobe Express** is the secondary creative workspace for illustration/style exploration and alternative visual treatments.
4. No design app may silently change canonical mechanics or wording.

## Change routing

### Mechanical/content change
`GitHub first -> validation -> Canva/Adobe sync -> export -> GitHub`

### Pure visual change
`Canva/Adobe -> compare against DESIGN_SYSTEM_MASTER.md -> user review -> export -> GitHub`
